# Empire Frontiers

A complete turn-based browser strategy game built with HTML, CSS, JavaScript, and the Canvas API.

## Play locally

1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. Choose a difficulty and select **Begin Conquest**.

No installation, web server, build tools, or external libraries are required.

## Files

- `index.html` — game interface
- `styles.css` — responsive visual design
- `game.js` — map generation, economy, combat, units, AI, upgrades, and saved-game logic

## Gameplay

Capture cities, expand territory, build mines, farms, and lumber camps, upgrade production, recruit armies, and conquer three computer-controlled empires. Game progress is saved locally in the browser.
